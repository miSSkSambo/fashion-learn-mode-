# Learn Mode — Fashion Classroom 🧵✨

An interactive **fashion learning and discovery web app** that combines education, creativity, and sustainability.  
Users can explore lessons on color theory, fabric types, fashion eras, cultural attire, and sustainable fashion — complete with quizzes, progress tracking, and a magazine-style reader.

---

## 🌟 Features

### 🎓 Learn Mode
- Bite-sized fashion lessons with **interactive labs** (color wheel, fabric picker, era slider, sustainability tracker)
- Real-time **progress saving** with localStorage
- Engaging **quizzes** for each topic

### 📰 Fashion Magazine
- Curated, filterable long-reads across five categories (Color, Fabric, Era, Culture, Sustainability)
- Built-in **reader mode** with next/prev navigation
- Search and filter controls for quick topic discovery

### 🎨 Interface
- Responsive, minimal **light/dark theme**
- Card-based modular design built with pure HTML, CSS, and vanilla JavaScript
- Optimized for both desktop and mobile

---

## 🚀 Quick Start

1. **Download or clone** the repository:
   ```bash
   git clone https://github.com/katlegosambo/fashion-learn-mode.git
   cd fashion-learn-mode
   ```

2. **Open `index.html`** in your browser — no installation or dependencies required.

3. Optional: enable **GitHub Pages** to host it live.
